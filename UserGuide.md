# User Guide: Running the ds-sim client


## 1. Open the project:

Open the github repository for this project in codespace


After opening the codespace for first time run:

```bash 
chmod +x ds-*
```

## 2. Run the main client tests:

Use this command

```bash
python3 ./ds_test.py "python3 client.py" -n -p 50000 -c TestConfigs
```
